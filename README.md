 Car Installment Calculator

 About
Car Installment Calculator is a web application that helps users calculate their monthly car installment based on the selected car brand, model, car price, down payment, and installment period.

 Features
- Select a car brand from five options: Hyundai, Toyota, Kia, BMW, and Mercedes.
- Choose a car model from the available models for each brand.
- Display the selected car's price automatically.
- Enter a down payment amount.
- Choose an installment period: 1, 2, 3, 4, 5, or 7 years.
- Calculate the interest rate based on the selected installment period.
- Calculate the monthly installment.
- Validate user inputs, such as checking that the down payment does not exceed the car price.

 Technologies Used
- HTML5
- CSS3
- Bootstrap
- JavaScript

How to Run
1. Download or clone this repository.
2. Make sure the following files are in the same project folder:
   - `index.html`
   - `style.css`
   - `cal.js`
   - `bootstrap.min.css`
   - `bootstrap.bundle.min.js`
   - The car image file
3. Open `index.html` in your web browser.
